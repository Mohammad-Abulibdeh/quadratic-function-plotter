# Quadratic Function Plotter | راسم الدالة التربيعية 📈

برنامج Python بسيط وتفاعلي برسم أي **دالة تربيعية** على الشكل:

```
f(x) = a·x² + b·x + c
```

بتدخل المعاملات `a` و `b` و `c`، والبرنامج بيرسم المنحنى وبيحسب ويعلّم عليه كل النقاط المهمة.

## 🧮 شو بيحسب؟

- **الرأس (Vertex):** `x = -b / 2a` وقيمته.
- **محور التماثل** (Axis of symmetry).
- **نقطة تقاطع المحور y** عند `(0, c)`.
- **جذور المعادلة** (نقاط تقاطع محور x)، إذا كان المميّز `b² - 4ac ≥ 0`.
- **اتجاه الفتحة:** لفوق إذا `a > 0`، ولتحت إذا `a < 0`.
- **المميّز (Discriminant)** وعدد الجذور الحقيقية.

كل النقاط بتنرسم على المخطط بألوان مختلفة مع شرح (legend).

## ▶️ التشغيل

```bash
pip install -r requirements.txt
python quadratic_plotter.py
```

بعدين أدخل القيم لما يطلبها، مثلاً:

```
Enter coefficient a: 1
Enter coefficient b: -2
Enter coefficient c: -3
```

وبتطلع نافذة فيها رسم الدالة مع الرأس والجذور ونقطة التقاطع.

## 🧰 المتطلبات

- Python 3
- [NumPy](https://numpy.org/) — لحساب قيم الدالة.
- [Matplotlib](https://matplotlib.org/) — للرسم.

## ⚠️ ملاحظات

- المعامل `a` لازم ما يكون صفر، وإلا المعادلة ما بتكون تربيعية (البرنامج بيمسك هالخطأ).
- مدى الرسم ثابت من `-10` لـ `10` على محور x.
